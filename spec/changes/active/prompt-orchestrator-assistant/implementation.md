## 待办（合并原 A6 Phase 3–5、评审缺口与知识库遗留）

### 1. 正确性与一致性

- 生图在途请求接入 `requestId` 取消；草稿/占位槽位不作为完成。
- 提示词测试与多模型对比补“停止”，传入 `requestId`。
- 反馈只写不读：`PromptFeedbackDB.list()` 接到反馈面板，补聚合视图。
- `prompt_test_runs` 保留策略与清理入口；删除 Prompt 时清理内存 AI 状态。
- 图片反推弹窗的停止需用视觉模型真实点击一次。

### 2. 交互与布局

- 统一 AI 运行状态条：阶段、首字、tok/s、停止；首字前用不确定进度，不伪造百分比。
- 结果区完成后切“完整提示词”，对比保留角标；窄窗 chips 最小宽度与横向滚动不挤压文字。
- 画布：属性面板固定、键盘微调、撤销/重做、框列表与画布联动。
- 写作层分区 chip 带 token、预算条、来源 badge；某包 contract 超预算的就地提示。
- 保存：目标文件夹/标签内联选择，记住上次目标。
- 死代码：`MAX_QUERIES_PER_CALL`、`PromptListView`（保留 `PromptFeedbackDB.list()` 供面板使用）。

### 3. 功能联动

- 存库按内容哈希去重，版本备注记 `runId`，保存后跳转。
- 测试结果一键送入测试弹窗并写历史；评分回写 feedback。
- Skill 库只读选择器；“用作知识包”走导入复制，不建运行时依赖。
- 生图工作台联动（尺寸/参考图/LoRA）；历史版本与回滚。
- 知识包：结果面板跳转包/模块正文；“另存为写作预设”；模块多选批量操作。

### 4. 稳定与兼容

- 90k 词库检索 p95；必要时加 FTS/索引，先证明 LIKE 缺行再改语义。
- 统一错误码/文案，IPC 不把原始异常抛给 UI；完成取消覆盖面审计。
- Windows 路径、GB18030、代理、DeepSeek/OpenAI/Gemini 协议回归。
- 选择性导出/自建同步/云端同步携带写作预设（需服务端资源类型，另开任务）。

### 5. prompt/new 整合

- 待确认：流程方案的运行合同、资料归属与排除范围；知识包扁平化方向的保留/迁移/撤回。
- 见 [design.md](design.md) 的“进行中设计”。
